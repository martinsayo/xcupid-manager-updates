# ⚽ Xcupid Manager Updates

Welcome to the official update configuration repository for **Xcupid Manager**, a football management game built by Xcupidevs.

## 📢 Purpose

This repository hosts public configuration information used by Xcupid Manager to check for game updates and display announcements from the developer.

## 🔄 Update System

The `config.json` file will contain information such as:

* The latest available version.
* The minimum version required to continue playing.
* The download link for the latest release.
* Update messages and developer announcements.

## 📥 Download

Game updates will initially be distributed through MediaFire. The download link may change if Xcupid Manager becomes available on Google Play.
